# Contributing to soroban-paystream

Thanks for your interest in contributing. This is an open-source Soroban smart contract — every contribution matters.

## How to contribute

1. Browse the open [Issues](https://github.com/OpenStreamFi/soroban-paystream/issues)
2. Comment on the issue you want to work on — wait for the maintainer to assign it to you
3. Fork the repo and create a branch: `git checkout -b feat/your-issue-name`
4. Make your changes
5. Run `cargo test` and make sure everything passes
6. Open a Pull Request with a clear description of what you changed and why

## Branch naming

- `feat/` for new features
- `fix/` for bug fixes
- `test/` for adding tests
- `docs/` for documentation
- `chore/` for config, CI, tooling

## PR requirements

- All tests must pass
- New functions must have rustdoc comments
- New functions must have at least one unit test

## Questions?

Open a Discussion on GitHub or reach out on the OpenStreamFi community channels.
